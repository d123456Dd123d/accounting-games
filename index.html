遊戲一：會計科目大分類挑戰

Game 1: Account Classification Challenge

將 34 個會計科目拖進資產、負債、業主權益、收益、費損五個籃子，答對放鞭炮、答錯著火，並記錄時間與正確率。

Drag 34 accounts into the Asset, Liability, Equity, Revenue, and Expense baskets. Correct drops set off fireworks, wrong drops start a fire; time and accuracy are recorded.
